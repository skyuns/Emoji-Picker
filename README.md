😃 Emoji 表情符號搜尋器

這是一個基於 Unicode 官方標準開發的高效繪文字搜尋工具。

### ✨ 核心功能：
* **海量收錄**：完整支援 3900+ 個 Unicode 表情符號。
* **三語並進**：內建繁中、簡中、英語三語系關鍵字對應。
* **智慧相容**：提供世代過濾器，配合在不同作業系統（如 Win 10/11）下顯示。
* **組合收集**：具備「收集區」功能，支援點擊組合多個圖案並一鍵複製。
* **字型補丁**：支援動態載入 Google Noto Color Emoji，增強顯示相容性。
* **極速搜尋**：採用 AI 輔助翻譯，以便搜尋中文關鍵字。

- Support for 3900+ Unicode official emojis.
- Trilingual keyword mapping (EN, ZH-TW, ZH-CN).
- Dynamic Google Noto font loading for enhanced compatibility.
- Interactive staging area for emoji combinations.
- Generation-based filtering (Win 11 / Win 10 / Legacy).
- AI-assisted Chinese keyword optimization.
